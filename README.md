# أذكاري - Azkari

مشروع أذكار المسلم اليومية (صباح / مساء / نوم / استغفار).

## التشغيل
افتح ملف `index.html` مباشرة في المتصفح.

## المميزات
- عداد لكل ذكر
- حفظ التقدم في المتصفح (localStorage)
- يعمل بدون إنترنت
- تصميم عربي RTL بسيط

## النشر على GitHub
بعد إنشاء المستودع على GitHub:
```bash
git remote add origin https://github.com/foof4316429-lang/azkari.git
git push -u origin main
```
